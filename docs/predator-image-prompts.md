# Predator Character Art Prompts — Filled In (for Gemini)

One filled-in prompt set (Stage 1 Spring, Stage 2 Summer, Stage 3 Fall) per predator,
generated from the same template style as the chicken prompts and the roster in
[`data/predators.json`](../data/predators.json). Per [`core_rules.md`](../core_rules.md),
predators level up at the end of Spring and Summer, so the 3 levels here are the
*same individual* growing more dangerous across the game's 3 seasons — not separate
creatures. Each predator's species-accurate visual facts are baked directly into all
3 prompt blocks below, so a copy-pasted code block is self-contained.

Generate one predator's 3 levels back-to-back in the same session so markings, coloring,
and art style stay consistent while the background shifts season-to-season and the
creature grows larger and more battle-worn.

Shared style notes (already baked into every prompt below): painterly gouache/watercolor,
Everdell/Cascadia-style character art, warm side lighting, muted warm palette shifting
per season, simple low-detail background vignette, no text/numbers/icons/UI chrome, 3:4
portrait aspect ratio, high-resolution print-quality with even margin for card-frame
cropping. Unlike the chickens, these are meant to read as dangerous/menacing in posture
and expression — but still within the same warm painterly style, not horror or gore.

## 1. Eggsmeralda — Snake

**Visual identity (baked into the prompts below):** Sleek scaled snake body with a diamond-blotched brown-and-tan pattern (corn-snake-like), a narrow triangular head, a flicking forked tongue, and no limbs.

### Stage 1 — Spring 🌱

```
Generate a painterly gouache/watercolor illustration of Eggsmeralda the Snake, a
predator antagonist for a cozy farming-village board game (style reference:
Everdell, Cascadia) — dangerous and menacing in posture and expression, but
still rendered in the game's warm, painterly art style, not horror or gore.
This is the Stage 1 (Spring) form of this predator.

Composition:
- Full-body, three-quarter view, body coiled with the head and neck raised, facing right, no legs
- Species-accurate appearance: Sleek scaled snake body with a diamond-blotched brown-and-tan pattern (corn-snake-like), a narrow triangular head, a flicking forked tongue, and no limbs.
- Posture and condition for this stage: lean and moderately sized, in an alert and wary stance — this is early in the game, before the predator has grown stronger
- Soft warm side lighting, gentle painterly brushwork, warm palette consistent
  with the game's overall art style
- Background: simple, low-detail vignette background evoking early spring — soft fresh greenery, budding leaves, a few pale blossom accents, cool-to-warm morning light — no scenery, no other characters, no text

Critical:
- No text, numbers, icons, logos, or UI chrome anywhere in the image
- No hard outlines / no flat vector style — must match the painterly gouache texture
```
